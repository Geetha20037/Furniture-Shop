# WOODORA Furniture Shop

Production-style React + Vite + Tailwind furniture e-commerce frontend.

## Run
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```

## Included
- Home page
- Product listing
- Category filtering
- Sorting
- Price/rating filters
- Pagination
- Product details
- Quick view
- Cart with quantity controls
- Wishlist
- Recently viewed
- Product comparison
- Search suggestions/navigation
- Login/signup validation
- Checkout validation
- Payment UI
- Order success
- Dark mode
- Toast notifications
- LocalStorage cart/wishlist/recent/compare/theme
- Skeleton component
- Lazy-loaded product images
- Responsive desktop/tablet/mobile design
- Smooth scrolling
- Hidden browser scrollbar
- Full-width layout with controlled responsive side padding
- No nested BrowserRouter
